# InvoiceFlow

InvoiceFlow is a small invoice-management application being built as a senior .NET developer take-home assignment.

**Technology:** .NET 10 and Blazor Web App with Interactive Server rendering.

## Architecture

- **Domain** — core domain model and rules.
- **Application** — use cases, abstractions, and orchestration.
- **Infrastructure** — implementations of application abstractions and persistence concerns.
- **Web** — Blazor application and composition root.

Detailed setup, design, and state-management documentation will be completed as implementation progresses.
